# Vijay's Portfolio Website

This is my personal portfolio project, built using React JS, CSS, JavaScript, Bootstrap, and React Router Dom. The project showcases my skills and experience in web development, with a focus on front-end projects.

## Features

- A collection of front-end projects that demonstrate my skills and expertise
- A clean and responsive design that adapts to different screen sizes and devices
- Easy navigation and routing using React Router Dom

## Technologies Used

- React JS
- CSS
- JavaScript
- Bootstrap
- React Router Dom

## Getting Started

To get started with this project, follow these steps:

1. Clone the repository to your local machine
2. Install the dependencies using `npm i`
3. Start the development server using `npm run dev`
4. Open your web browser and navigate to `http://localhost:5173` to view the project

## Project Structure

The project is organized into the following directories:

- `public`: contains static assets and index.html
- `src`: contains the React components, CSS files, and JavaScript files
- `components`: contains reusable React components
- `pages`: contains page-level React components
